티처블 머신 모델 파일은 "실험실마다" 아래 폴더에 넣으세요.

  public/model/bio/    ← 생물실
  public/model/phys/   ← 물리실
  public/model/chem/   ← 화학실
  (실험실을 새로 만들면 그 실험실 영어 코드 이름의 폴더가 자동으로 생겨요)

각 폴더에 넣을 파일 3개:
  model.json
  metadata.json
  weights.bin

- 파일이 없으면 그 실험실 태블릿은 자동으로 "연습용 가짜 모델"을 씁니다. (화면에 "연습 모드" 상자가 보임)
- 파일 3개를 넣고 그 실험실 태블릿 화면을 새로 고치면 코드 수정 없이 진짜 모델로 바뀝니다.
- 예전처럼 이 폴더(public/model/) 바로 아래에 넣은 모델은 생물실(첫 번째 실험실) 모델로 계속 쓰입니다.
  생물실 폴더(public/model/bio/)에 모델이 있으면 그쪽을 먼저 씁니다.
- 새 모델을 넣은 뒤에는 관리자 화면 "모델 연결" 탭에서 그 실험실을 골라 경고가 없는지 확인하세요.
- 만드는 방법은 README.md 의 "티처블 머신으로 모델 만들기"를 보세요.
