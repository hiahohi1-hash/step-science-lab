# 🧪 과학실 통합 관리 웹 앱

과학실의 **시약 반출**과 **실험 기구 사용 현황**을 한곳에서 관리하는 웹 앱입니다.

- **시약:** 누가, 어떤 시약을, 언제, 왜 가져갔는지 기록해요. 반납 기한을 알려 주고, 연체는 바로 경고해요.
- **기구:** 고압 멸균기·배양기처럼 오래 쓰는 기구가 지금 사용 중인지, 언제 끝나는지 보여 줘요. 대기 순서를 관리하고 사용법도 안내해요.
- **카메라:** 시약 바코드나 라벨의 카스 번호를 읽고, 기구는 **직접 학습시킨 딥러닝 모델(티처블 머신)**로 사진만 보고 알아봐요.

## 1. 준비물

| 준비물 | 설명 |
|---|---|
| 서버 컴퓨터 1대 | 윈도우·맥 모두 돼요. 앱이 켜져 있는 동안 계속 켜 두어야 해요. 교무실 컴퓨터를 추천해요 (관리자 알림을 받기 좋음). |
| Node.js 22 이상 | [nodejs.org](https://nodejs.org) 에서 **LTS** 버전(24 등)을 받아 설치하세요. 터미널에서 `node -v`로 확인할 수 있어요. |
| 태블릿 1대 | 과학실 입구에 두는 "처음 화면"용. **뒤쪽 카메라**가 있어야 해요. |
| 같은 와이파이 | 서버 컴퓨터와 태블릿·휴대폰이 **같은 와이파이**에 연결되어 있어야 해요. |

> 💰 이 앱은 **돈이 드는 서비스를 하나도 쓰지 않아요.** 가입·카드 등록·유료 API가 없어요.

## 2. 설치하기

1. 이 폴더(`과학실관리`)를 서버 컴퓨터에 둡니다.
2. 터미널(윈도우는 "명령 프롬프트" 또는 "PowerShell")을 열고 이 폴더로 이동합니다.
   ```bash
   cd 과학실관리
   ```
3. 필요한 패키지를 설치합니다. 인터넷이 필요하고 1~2분쯤 걸려요.
   ```bash
   npm install
   ```
4. 설치가 끝나면 보안 검사를 해 보세요. `found 0 vulnerabilities`가 나오면 좋아요.
   ```bash
   npm audit
   ```

> 🔒 이 폴더의 `.npmrc`에는 `ignore-scripts=true`가 들어 있어요. 패키지를 설치할 때 **남이 만든 패키지의 설치 명령이 이 컴퓨터에서 실행되지 않게** 막는 설정이에요. 이 앱은 설치 명령이 하나도 필요 없어요 (데이터베이스 패키지는 윈도우·맥용 완성 파일을 이미 갖고 있어요). **지우지 마세요.**

## 3. .env 설정

`.env`는 **비밀 정보**를 넣는 파일이에요. **다른 사람에게 보내거나 인터넷에 올리지 마세요.**

1. `.env.example` 파일을 복사해서 이름을 `.env`로 바꿉니다.
   ```bash
   copy .env.example .env
   ```
   맥은 `cp .env.example .env`
2. `.env`를 메모장으로 열어 값을 확인합니다.

| 이름 | 뜻 | 기본값 |
|---|---|---|
| `HTTP_PORT` | 이 컴퓨터에서 `http://localhost:이번호` 로 들어가요. 다른 기기에서는 이 주소로 못 들어와요 (암호화가 안 돼서 일부러 막음). | 3000 |
| `HTTPS_PORT` | 태블릿·휴대폰은 `https://(컴퓨터 IP):이번호` 로 들어와요. | 3443 |
| `ADMIN_PASSWORD` | 관리자 **처음** 비밀번호. 처음 로그인하면 바로 새 비밀번호로 바꾸게 돼요. | change-me-1234 |

## 4. 실행하기

```bash
npm start
```

이렇게 나오면 성공이에요.

```
✔ 데이터베이스 준비 완료: 시약 10종, 기구 6대
✔ 1분마다 자동 검사를 시작했어요.
✔ 이 컴퓨터에서 보기:   http://localhost:3000
✔ https 로 보기:        https://localhost:3443
✔ 태블릿·휴대폰에서 보기: https://192.168.0.5:3443   (같은 와이파이에 연결해야 해요)
```

| 화면 | 주소 | 누가 |
|---|---|---|
| 처음 화면 (태블릿) | `/` | 학생 |
| 기구 현황판 | `/status` | 학생 (휴대폰, 로그인 없음) |
| 관리자 화면 | `/admin` | 담당 선생님 (비밀번호) |

- 끄려면 터미널에서 `Ctrl + C`를 누르세요.
- 처음 실행하면 `data/lab.db`(데이터베이스)와 `certs/`(https 인증서)가 자동으로 생겨요.
- 데이터베이스 내용을 표로 보고 싶으면 `npm run db:show`를 실행하세요.

## 5. 처음 실행한 뒤 할 일

1. **관리자 비밀번호 바꾸기**
   - 서버 컴퓨터에서 `http://localhost:3000/admin`에 들어가 `.env`의 비밀번호로 로그인하세요.
   - 새 비밀번호(8글자 이상)로 바꾸는 화면이 바로 나와요. 바꾸기 전에는 다른 기능을 쓸 수 없어요.
2. **알림 켜기**
   - 관리자 화면 오른쪽 위 **🔕 알림 켜기** → 브라우저가 물으면 **허용**을 누르세요.
   - 관리자 화면을 켜 두면 반출, 승인 요청, 연체 등이 생길 때 **컴퓨터 알림 창 + 삐 소리 + 탭 제목 숫자**로 알려 줘요.
3. **예시 데이터 고치기**
   - **시약 관리** 탭: 예시 시약 10종의 보관 위치와 병 수는 임시 값(`시약장`, `1병`)이에요. 실제 값으로 고치세요. 바코드는 **📷 바코드 찍기**로 넣을 수 있어요.
   - **기구 관리** 탭 → **수정** → **📷 사진 넣기**로 기구 사진을 넣으면 태블릿·현황판·"1번/2번 고르기"에 사진이 보여요 (선택). 휴대폰으로 바로 찍어도 돼요.
   - **기구 관리** 탭: 예시 사용법·주의사항 맨 위에 "⚠ 학교 기구 설명서를 보고 담당 교사가 검토해야 하는 예시 내용입니다"가 있어요. **학교 기구 설명서와 비교해 고친 뒤** 그 줄을 지우세요. 특히 고압 멸균기는 기종마다 다르니 꼭 확인하세요.
4. **실험실 정하기:** 처음 화면을 처음 열면 "이 태블릿은 어느 실험실에 있나요?"가 나와요. 그 태블릿이 놓인 실험실을 고르세요 (생물실·물리실·화학실). 실험실은 관리자 화면 **실험실** 탭에서 추가하거나 이름을 바꿀 수 있어요.
5. **설정** 탭에서 반출 시간, 연장 시간, 고위험 반납 시각, 예약 대기 시간을 학교 규칙에 맞추세요.

## 6. 태블릿과 휴대폰에서 접속하기

### ⚠ 카메라는 https 주소나 localhost에서만 켜져요
브라우저는 보안 때문에 `http://192.168…` 같은 주소에서는 카메라를 막아요. 그래서 이 앱은 **https 서버(포트 3443)**도 함께 켜요.

### 접속 순서
1. 태블릿을 서버 컴퓨터와 **같은 와이파이**에 연결합니다.
2. 서버를 켤 때 터미널에 나온 `태블릿·휴대폰에서 보기` 주소(예: `https://192.168.0.5:3443`)를 태블릿 브라우저에 입력합니다.
3. **"연결이 비공개로 설정되어 있지 않습니다"** 경고가 나와요. 이 컴퓨터가 직접 만든 인증서(자체 인증서)라서 **처음 한 번은 나오는 게 정상**이에요.
   - **안드로이드(크롬):** **고급** → **(주소)(으)로 이동(안전하지 않음)**
   - **아이패드·아이폰(사파리):** **세부사항 보기** → **이 웹 사이트 방문**
4. **📷 카메라로 찍기**를 누르고 카메라 사용을 **허용**합니다.
5. 처음 화면 오른쪽 위 **🔇 알림 소리 켜기**를 한 번 누릅니다. 브라우저 규칙상 화면을 한 번 눌러야 소리를 낼 수 있어요.

### 카메라를 실수로 "차단"했다면
- **크롬(컴퓨터·안드로이드):** 주소창 왼쪽 자물쇠(또는 ⓘ) 아이콘 → **카메라** → **허용** → 새로 고침
- **아이패드(사파리):** 설정 앱 → **Safari** → **카메라** → **허용**

### 휴대폰으로 기구 현황 보기
- 같은 와이파이에서 `https://(컴퓨터 IP):3443/status`에 들어가요.
- 학번은 `203**`처럼 가려서 보여요.
- 위쪽 **실험실 탭**(전체 / 생물실 / …)으로 골라 볼 수 있어요. `/status?lab=번호` 주소를 즐겨찾기 해 두면 그 실험실이 바로 보여요.
- 대기 등록을 했다면 현황판에 학번을 넣고 **알림 켜기**를 누르세요. 차례가 되면 화면 안내, 소리, 진동(안드로이드)으로 알려 줘요.
  - ⚠ 휴대폰 브라우저는 자체 인증서 주소에서 **브라우저 알림 창**을 막는 경우가 많아요. 그래서 **현황판 화면을 켜 둔 상태**에서 소리·진동으로 알려 주는 방식을 같이 써요.

> 💡 컴퓨터 IP 주소는 와이파이에 따라 바뀔 수 있어요. 서버를 켤 때마다 터미널의 주소를 확인하세요. IP가 바뀌면 인증서도 자동으로 다시 만들어져서 경고가 한 번 더 나와요.

## 7. 화면별 사용법

### 처음 화면 (태블릿) — 학생
- **📷 카메라로 찍기:** 시약 바코드를 먼저 찾고, 없으면 기구 사진 인식을 해요.
  - 시약 바코드가 없으면 **🔤 라벨 글자 읽기**를 누르세요. 라벨의 카스 번호(예: `7647-01-0`)를 읽어 시약을 찾아요.
  - 기구는 **기구 전체가 화면 가운데 점선 안에 들어오게** 비추세요.
- **시약 반납하기 / 시약 연장하기:** 학번을 넣으면 내 기록이 나와요.
- **시약 직접 찾기 / 기구 직접 찾기:** 카메라가 없거나 인식이 안 될 때 써요.
- 아래쪽 **기구 지금 상태:** 모든 기구의 상태와 남은 시간을 보여 줘요.
- 맨 위 **빨간 띠:** 연체가 있으면 "연체 중: 염산 (학번 203**, 3시간 지남)"이 떠요.
- 결과 화면은 5초 뒤, 아무것도 안 누르면 90초 뒤 처음 화면으로 돌아가요.
- **여러 실험실:** 태블릿마다 실험실을 정해 두면 기구 찾기·카메라 인식·기구 상태 줄에 **그 실험실 것만** 보여요. 시약은 그 실험실에서 먼저 찾고, 없으면 다른 실험실 시약도 보여 줘요. **시약 반납·연장은 실험실과 상관없이** 내 기록이 모두 나와요. 바꾸려면 처음 화면 맨 아래 **🏫 실험실 바꾸기**.

### 안내 전용 기구 (마이크로피펫, 피펫 에이드 …)
- 예약·대기가 필요 없지만 쓰는 법이 어려운 기구예요. 카메라로 찍거나 "기구 직접 찾기"로 고르면 **사진 · 쓰기 전 확인 · 사용법 · 주의사항** 화면이 바로 나와요. 학번 입력은 없어요.
- 처음 화면 상태 줄과 현황판에는 나오지 않아요.
- 관리자 화면 **기구 관리 → 기구 추가/수정 → 종류: 📘 안내 전용**으로 만들어요. 예시로 생물실에 마이크로피펫·피펫 에이드가 들어 있어요 (⚠ 교사 검토 필요).
- 카메라로 인식하려면 티처블 머신에 분류(예: `micropipette`, `pipette_aid`)를 만들고 "모델 연결" 탭에서 연결하세요.

### 🔎 추천하는 도구 (실험 주제로 추천)
- 처음 화면 **"🔎 추천하는 도구"** 칸("주제를 입력해주세요")에 "효모 발효", "DNA 추출", "세균 배양"처럼 적으면 두 묶음으로 추천해요.
  - **🔬 주로 사용하는 기구** (예약 기구, 지금 상태도 함께)
  - **🧪 주로 사용하는 기자재** (안내 전용, 누르면 사용법)
- 추천 근거:
  1. 선생님이 기구마다 적어 둔 **키워드** (관리자 → 기구 관리 → "쓰이는 실험·키워드"). 쓴 말이 그대로 맞으면 +3, 비슷한 말로만 맞으면 +1, 주제가 키워드와 통째로 같으면 +5 더.
  2. **비슷한 말** (관리자 → 설정 → "주제로 찾기 — 비슷한 말", 예: 세균·박테리아·미생물)
  3. 학생들이 **실제로 적은 실험 주제** (아래)
  - 점수가 같으면 실제로 많이 쓰인 기구가 먼저 나와요. 그 실험실에 맞는 기구가 없으면 다른 실험실 기구를 보여 줘요.
- **실험 주제 모으기 (선택):** 예약 기구를 사용 시작할 때, 안내 전용 기구 사용법 화면 아래에서 "어떤 실험(주제)에 쓰시나요?"를 적을 수 있어요.
  - **학번·이름은 저장하지 않아요.** 학번처럼 보이는 숫자(5자리 이상)가 들어가면 받지 않아요.
  - 관리자 화면 **주제 기록** 탭에서 기구별로 많이 나온 주제를 보고 **"키워드에 추가"**하거나, 이상한 글은 **삭제**하세요.
  - 한 기기에서 한 시간에 30번까지만 보낼 수 있어요 (일부러 추천을 흐리는 것 방지).
- 예시 키워드는 생물실 기구 8개에 넣어 두었어요 (⚠ 교사 검토 필요).
- **물리실·화학실을 바로 쓰려면:** 관리자 → **기자재 자료집** 탭에서 학교에 있는 기자재를 체크해 넣으세요. 넣자마자 "옴의 법칙 → 직류 전원 장치·멀티미터", "중화 적정 → 뷰렛·피펫" 처럼 추천돼요. 사용법은 비어 있으니 "기구 관리"에서 적어 주세요.
- 추천 점수: "반응", "법칙"처럼 뜻이 약한 말은 +1만 주고, 묶음마다 1등 점수의 45%가 안 되는 기구는 보여 주지 않아요. 추천은 참고용이고, 실험 계획은 꼭 선생님과 확인하세요.

## 8. 티처블 머신으로 기구 인식 모델 만들기

[티처블 머신(Teachable Machine)](https://teachablemachine.withgoogle.com)은 구글이 만든 **무료** 도구예요. 사진을 보여 주면 브라우저 안에서 딥러닝 모델을 학습시켜 줘요. 코딩이 필요 없어요.

> 🔒 학습은 **내 컴퓨터 브라우저 안에서** 해요. 사진이 구글 서버로 올라가지 않아요. 단, 내보낼 때 "업로드(공유 링크)"를 고르면 모델이 인터넷에 올라가니 **꼭 "다운로드"를 고르세요** (8-4).

### 8-1. 분류(클래스) 정하기
이 앱의 기본 분류 이름은 아래와 같아요. **티처블 머신에서 이름을 똑같이** 지으면 연결 표를 따로 고칠 필요가 없어요. 영어 소문자이고, 띄어쓰기 대신 `_`를 써요.

| 분류 이름 | 기구 | 비고 |
|---|---|---|
| `autoclave` | 고압 멸균기(오토클레이브) | |
| `incubator` | 배양기 | 1번(창가)·2번(문 쪽) **두 대를 한 분류로** 찍어요. 어느 쪽인지는 인식 뒤 학생이 골라요. |
| `centrifuge` | 원심분리기 | |
| `dryer` | 건조기 | |
| `clean_bench` | 무균 작업대(클린벤치) | |
| `micropipette` | 마이크로피펫 (안내 전용) | 찍으면 사용법이 나와요 |
| `pipette_aid` | 피펫 에이드 (안내 전용) | |
| `not_equipment` | **기구 아님** | **꼭 만들어야 해요!** 아래 8-3 참고 |

### 8-2. 사진 찍는 요령 📸 (정확도의 90%가 여기서 결정돼요)

**① 실제로 쓸 태블릿으로 찍으세요**
- 과학실 입구 태블릿의 **뒤쪽 카메라**로 찍은 사진이 가장 좋아요. 학습할 때와 쓸 때의 카메라가 같아야 잘 맞혀요.
- 태블릿으로 티처블 머신 사이트에 들어가 **웹캠** 버튼으로 바로 찍을 수 있어요.

**② 한 분류에 200~300장**
- 처음에는 분류마다 **최소 100장**, 좋게는 200~300장을 찍으세요.
- **분류끼리 장수를 비슷하게** 맞추세요. 한 분류만 많으면 모델이 그쪽으로 치우쳐요.

**③ 여러 가지로 바꿔 가며 찍으세요** — 같은 사진만 많으면 소용없어요.
| 바꿀 것 | 예 |
|---|---|
| 각도 | 정면, 왼쪽·오른쪽 45도, 조금 위에서, 조금 아래에서 |
| 거리 | 기구 전체가 꽉 차게, 조금 멀리(주변이 보이게), 학생이 실제로 서 있을 거리 |
| 빛 | 형광등 켰을 때·껐을 때, 아침·오후 햇빛, 블라인드 올렸을 때·내렸을 때 |
| 기구 상태 | 문 열림·닫힘, 화면 켜짐·꺼짐, 위에 물건이 있을 때·없을 때 |
| 가려짐 | 사람 손이나 몸이 조금 가렸을 때 |
| 흔들림 | 살짝 흔들린 사진도 몇 장 (학생이 손으로 들고 비추니까요) |

**④ 헷갈리기 쉬운 기구는 "다른 점"을 더 찍으세요**
- **배양기와 건조기**는 둘 다 네모난 상자라서 헷갈리기 쉬워요.
- **조작판, 온도 표시창, 상표·모델명 스티커, 손잡이 모양**처럼 서로 다른 부분이 잘 보이는 사진을 더 찍으세요.
- 기구 앞에 **이름표 스티커**(예: 큰 글씨 "배양기")를 붙이면 정확도가 크게 올라가요.

**⑤ 화면 가운데에 오게**
- 모델은 사진 **가운데 정사각형 부분**을 봐요. 찍을 때도 기구가 화면 **가운데**에 오게 하세요.

**⑥ 사진을 따로 조금 남겨 두세요 (탐구 보고서용)**
- 분류마다 20~30장은 학습에 넣지 말고 따로 두세요.
- 나중에 모델을 시험하는 데 쓰면 "학습에 쓰지 않은 사진으로도 맞히는지"를 보고서에 쓸 수 있어요.

### 8-3. "기구 아님(`not_equipment`)" 분류 만들기 — 꼭!
이 분류가 없으면 모델은 **무엇을 비추든** 5개 기구 중 하나라고 우겨요. 카메라를 책상에 돌려도 "건조기 60%" 같은 결과가 나와요.

**찍을 것 (200~300장):**
- 과학실 바닥, 벽, 천장, 창문, 문
- 책상, 의자, 실험대 위 (기구가 없는 곳)
- 사람 얼굴·손·몸 (학생이 태블릿 앞에 서 있는 모습)
- **목록에 없는 다른 기구**: 현미경, 저울, 비커, 시약장, 냉장고 등
- **시약병** (시약은 바코드로 따로 찾으니까 "기구 아님"이어야 해요)
- 흐릿하거나 너무 어두운 사진

이 앱은 결과가 "기구 아님"이면 **아무 반응 없이** 계속 기다려요.

### 8-4. 티처블 머신에서 순서대로 하기
1. [teachablemachine.withgoogle.com](https://teachablemachine.withgoogle.com) → **시작하기(Get Started)**
2. **이미지 프로젝트(Image Project)** → **표준 이미지 모델(Standard image model)**
3. 분류 이름 바꾸기: `Class 1` 옆 **연필 아이콘** → `autoclave` 입력. `Class 2` → `incubator` …
   - **클래스 추가(Add a class)**로 6개(`not_equipment` 포함)를 만드세요.
   - ⚠ 이름은 **대·소문자, 띄어쓰기까지 똑같이** 써야 해요.
4. 사진 넣기
   - **웹캠(Webcam)**: **길게 눌러서 녹화(Hold to Record)**를 누르고 있는 동안 계속 찍혀요. 누르고 있는 동안 태블릿을 천천히 움직여 각도·거리를 바꾸세요.
   - **업로드(Upload)**: 미리 찍어 둔 사진을 한꺼번에 넣어요.
5. **모델 학습시키기(Train Model)**를 누르고 기다려요. 학습하는 동안 **탭을 닫거나 다른 탭으로 옮기지 마세요.**
   - (선택) **고급(Advanced)**: 에포크(Epochs) 50, 배치 크기(Batch Size) 16, 학습률(Learning Rate) 0.001. 처음에는 기본값 그대로도 괜찮아요.
6. 오른쪽 **미리보기(Preview)**에서 웹캠으로 기구를 비춰 잘 맞히는지 확인해요.
7. **모델 내보내기(Export Model)** → **Tensorflow.js** 탭 → **다운로드(Download)** 선택 → **내 모델 다운로드(Download my model)**
   - ⚠ **업로드(Upload my model / 공유 링크)**는 고르지 마세요. 모델이 인터넷에 공개돼요.
   - `tm-my-image-model.zip` 같은 압축 파일이 내려받아져요.
8. **프로젝트 저장하기:** 나중에 사진을 더 넣어 다시 학습하려면 꼭 해 두세요.
   - 왼쪽 위 **≡ 메뉴** → **프로젝트를 파일로 다운로드(Download project as file)**
   - `.tm` 파일이 생겨요. 다음에 **≡ → 파일에서 프로젝트 열기**로 이어서 할 수 있어요.

## 9. 모델 넣고 연결하기, 정확도 확인

### 9-1. 모델 파일 넣기 (실험실마다 따로)
1. 내려받은 압축 파일을 풀면 파일 3개가 나와요: `model.json`, `metadata.json`, `weights.bin`
2. **그 실험실 폴더**에 3개를 넣어요. 이미 있으면 덮어쓰기.
   | 실험실 | 폴더 |
   |---|---|
   | 생물실 | `public/model/bio/` |
   | 물리실 | `public/model/phys/` |
   | 화학실 | `public/model/chem/` |
   - 실험실을 새로 만들면 그 영어 코드 이름의 폴더가 자동으로 생겨요.
   - 예전처럼 `public/model/` 바로 아래에 넣은 모델은 **생물실** 모델로 계속 쓰여요.
3. 서버는 끄지 않아도 돼요. **그 실험실 태블릿 화면을 새로 고치면** 진짜 모델로 바뀌어요.
4. 실험실마다 따로 학습시키면 한 모델이 구분할 기구 수가 적어져서 **정확도가 더 높아요.** 각 모델에 `not_equipment`(기구 아님) 분류를 꼭 넣으세요.
   - 파일이 없을 때는 자동으로 **🧪 연습 모드**(가짜 모델)가 켜져요.
   - 연습 모드에서는 화면 아래 노란 상자에서 "보이는 척할 기구"와 확신도를 골라 흐름을 연습할 수 있어요.

### 9-2. "모델 연결" 탭에서 확인
관리자 화면 → **모델 연결** 탭을 열고, 위쪽에서 **실험실**을 고릅니다 (실험실마다 모델이 따로라서 "전체"는 없어요).
- **지금 쓰는 모델**에 "✔ 진짜 모델"과 분류 목록이 나오는지 확인해요.
- **⚠ 경고**가 있으면 해결하세요.
  | 경고 | 해결 |
  |---|---|
  | 모델에 있지만 기구와 연결되지 않은 분류 이름 | 표에서 그 분류에 기구를 체크하고 **저장** |
  | 모델에 "기구 아님" 분류가 없어요 | 티처블 머신에 `not_equipment` 분류를 만들거나, **인식 설정**에서 "기구 아님" 이름을 모델에 맞게 바꾸기 |
  | 연결 표에는 있지만 지금 모델에는 없는 분류 이름 | 이름을 바꿨다면 새 이름으로 다시 연결하고, 옛 이름은 체크를 모두 풀고 저장 |
  | 카메라로 인식할 수 없는 기구 | 그 기구는 "기구 직접 찾기"로만 고를 수 있어요. 필요하면 모델에 분류를 추가하세요. |
- **같은 종류 여러 대**는 한 분류에 여러 기구를 체크하면 돼요 (예: `incubator` → 배양기 1번 + 2번).
- **인식 설정**
  - 자동 결정 확신도 기준: 기본 80%
  - 같은 결과가 이어져야 하는 시간: 기본 2초
  - 후보를 보여 줄 시간: 기본 5초

### 9-3. 인식이 어떻게 결정되나요?
| 상황 | 앱의 반응 |
|---|---|
| 같은 기구가 **2초 동안 계속 80% 이상** | 그 기구로 결정 → "고압 멸균기가 맞나요?" |
| 80% 미만이거나 결과가 계속 바뀜 | **5초 뒤** "후보: 건조기 62%, 배양기 30%, …" 중에서 고르기 (없으면 "기구 직접 찾기") |
| "기구 아님" | 아무 반응 없이 계속 인식 |
| 같은 종류가 여러 대 | "1번(창가) / 2번(문 쪽)" 고르기 |

### 9-4. "인식 정확도" 탭 (탐구 보고서 자료)
학생이 카메라로 기구를 인식하고 기구 화면까지 들어갈 때마다 기록이 쌓여요. 기록되는 것: 모델이 예측한 기구, 확신도, 학생이 최종 확인한 기구.
- **정확도** = 모델이 처음 예측한 기구가 학생이 **최종 확인한 기구와 같은 비율**
- **기구별 정확도:** 기록 5건 이상인데 80% 미만이면 빨간 줄과 함께 **"사진을 더 찍어 다시 학습시키세요"**가 떠요.
- **자주 헷갈린 기구 짝:** 예) "건조기 ↔ 배양기 3번 — 배양기를 건조기로 3번"
- **실험실·모델 고르기:** 실험실별로 보거나, 모델을 바꾼 앞뒤 정확도를 비교할 수 있어요.
- **📥 인식 기록 CSV:** 엑셀로 그래프를 그려 보고서에 쓰세요.

**다시 학습시키는 순서:**
1. 정확도가 낮은 기구와 헷갈린 짝을 확인해요.
2. 그 기구의 사진을 [8-2](#8-2-사진-찍는-요령--정확도의-90가-여기서-결정돼요) 요령대로 더 찍어요. 헷갈린 상대 기구와 **다른 점**이 보이게 찍어요.
3. 저장해 둔 `.tm` 프로젝트를 열어 사진을 추가하고 다시 학습 → 내보내기
4. `public/model/`에 덮어쓰고 태블릿을 새로 고쳐요.
5. 며칠 쓴 뒤 정확도 탭에서 **새 모델**을 골라 전과 비교해요.

## 11. 자주 생기는 문제 해결

| 문제 | 해결 |
|---|---|
| `npm`을 찾을 수 없다고 나와요 | Node.js를 설치한 뒤 **터미널을 새로 열어** 다시 해 보세요. |
| `npm install`에서 `gyp ERR! … Visual Studio` 오류 | 폴더에 `.npmrc` 파일(`ignore-scripts=true`)이 있는지 확인하세요. 없으면 다시 만들고 `node_modules` 폴더를 지운 뒤 `npm install`을 다시 하세요. Node.js가 **22 이상**인지도 확인하세요 (`node -v`). |
| `EADDRINUSE` (주소가 이미 사용 중) | 서버가 이미 켜져 있거나 다른 프로그램이 3000/3443번을 쓰고 있어요. 다른 터미널의 서버를 끄거나 `.env`의 포트 번호를 바꾸세요. |
| 태블릿에서 주소가 안 열려요 | ① 같은 와이파이인지 확인 ② 주소가 **https**와 **:3443**인지 확인 ③ 윈도우 방화벽이 물으면 **허용** ④ 학교 와이파이가 기기끼리 연결을 막을 수 있어요. 휴대폰 핫스팟에 둘 다 연결해서 시험해 보세요. |
| "연결이 비공개로 설정되어 있지 않습니다" | 자체 인증서라서 정상이에요. [6장](#6-태블릿과-휴대폰에서-접속하기)처럼 **고급 → 계속**을 누르세요. |
| "이 주소에서는 카메라를 쓸 수 없어요" | `http://`로 들어왔어요. `https://(IP):3443`으로 들어오세요. |
| "카메라 사용이 허용되지 않았어요" | [6장 "차단했다면"](#카메라를-실수로-차단했다면)을 보세요. |
| "다른 프로그램이 카메라를 쓰고 있어요" | 카메라 앱, 화상 회의 앱을 닫으세요. |
| Claude 앱 안의 브라우저에서 카메라가 안 켜져요 | 그 브라우저는 카메라를 막아 둬요. 크롬·엣지·태블릿 브라우저에서 여세요. |
| 바코드를 못 읽어요 | 바코드를 화면 가운데에 **가로로**, 15~25cm 거리에서 비추세요. 반사가 심하면 각도를 조금 바꾸세요. 그래도 안 되면 🔤 라벨 글자 읽기를 쓰세요. |
| "등록된 시약이 없어요" (바코드) | 선생님이 **시약 관리 → 수정 → 📷 바코드 찍기**로 바코드를 등록하세요. |
| 라벨 글자 읽기가 카스 번호를 못 찾아요 | 카스 번호가 화면 가운데에 **크고 또렷하게** 보이게, 흔들리지 않게 찍으세요. 처음 한 번은 10초쯤 걸릴 수 있어요. |
| 기구 인식이 엉뚱해요 / 늘 후보 화면만 떠요 | **인식 정확도** 탭을 확인하고 [8-2 사진 찍는 요령](#8-2-사진-찍는-요령--정확도의-90가-여기서-결정돼요)대로 다시 학습시키세요. "기구 아님" 분류가 있는지도 확인하세요. |
| 새 모델을 넣었는데 연습 모드가 그대로예요 | 파일 3개가 **그 실험실 폴더(예: `public/model/bio/`) 바로 아래**에 있는지 (폴더 안의 폴더가 아닌지) 확인하고, 그 실험실 태블릿을 새로 고치세요. |
| "기구 인식 모델을 불러오지 못했어요" | 파일 3개가 **같은 때 함께** 내보낸 것인지 확인하세요. 티처블 머신에서 **Tensorflow.js → 다운로드**로 내보냈는지 확인하세요. |
| 소리가 안 나요 | 화면을 새로 열 때마다 **🔇 알림 소리 켜기**를 한 번 눌러야 해요. 태블릿 볼륨과 무음 모드도 확인하세요. |
| 관리자 컴퓨터 알림 창이 안 떠요 | **🔕 알림 켜기**를 누르고 **허용**했는지 확인하세요. 차단했다면 주소창 자물쇠 → 알림 → 허용. 윈도우 "집중 지원(방해 금지)"이 켜져 있어도 안 떠요. |
| "비밀번호를 여러 번 틀려서 잠시 막혔어요" | 5분 기다리세요. (서버를 껐다 켜도 풀려요.) |
| **관리자 비밀번호를 잊었어요** | 서버를 끄고 아래 명령을 실행한 뒤 다시 켜세요. 그러면 `.env`의 `ADMIN_PASSWORD`가 다시 처음 비밀번호가 되고, 로그인하면 바로 새 비밀번호로 바꾸게 돼요. ↓ |
| 기구 화면에 "대기 등록하기"가 없어요 | 대기 기능이 **기본으로 꺼져 있어요** (학생은 지금 누가 쓰는지만 봐요). 필요하면 관리자 → 설정 → "기구 대기 기능 쓰기"를 켜세요. |
| "추천하는 도구"에 아무것도 안 나와요 | 그 실험실에 맞는 기구가 등록되지 않았을 수 있어요. 관리자 → **기자재 자료집**에서 기자재를 넣거나, 기구 관리에서 키워드를 적어 주세요. |
| 화면이 이상하거나 예전 모습이에요 | 브라우저에서 새로 고침(F5). 안 되면 `Ctrl + Shift + R`. |
| 기구 사진이 안 올라가요 | JPG·PNG 사진인지 확인하세요. 아이폰 HEIC 사진은 열지 못할 수 있어요 (설정 → 카메라 → 포맷 → "가장 호환성 높은 형식"). |
| 데이터를 백업하고 싶어요 | 서버를 끈 뒤 `data/lab.db` 파일과 `uploads/` 폴더(기구 사진)를 USB 등에 복사하세요. 되돌릴 때는 다시 제자리에 넣으면 돼요. |

## 12. 보안과 개인정보

- **학생 정보는 학교 컴퓨터 밖으로 나가지 않아요.**
  - 알림은 외부 메신저 대신 관리자 화면으로만 와요.
  - 카메라 사진은 서버로도 보내지 않고 **태블릿 안에서만** 인식해요.
  - 글자 인식 데이터와 모델도 모두 이 컴퓨터에서 보내요. 인터넷이 막혀도 동작해요.
- **학번·이름 전체는 관리자 화면에서만** 보여요. 나머지 화면과 실시간 소식에는 학번을 `203**`처럼 가리고 이름은 넣지 않아요.
- **관리자 비밀번호**
  - 암호화(scrypt)해서 저장해요.
  - 5번 틀리면 5분 동안 잠겨요. 로그인은 8시간 뒤 자동으로 풀려요.
  - 예시 비밀번호로는 비밀번호 바꾸기 말고 아무것도 할 수 없어요.
- **http(3000번)는 이 컴퓨터에서만** 열려요. 다른 기기는 암호화된 https로만 들어와요.
- **CSV 내려받기:** 엑셀 수식처럼 보이는 글자(`=`, `+`, `-`, `@`로 시작)는 실행되지 않게 바꿔서 저장해요.
- **1년 지난 기록의 학번·이름 자동 지우기**를 설정에서 켤 수 있어요.
- **기구 사진**
  - 관리자만 올릴 수 있어요.
  - 올리기 전에 관리자 화면이 사진을 1024px 이하 JPEG로 다시 그려서, 휴대폰 사진 속 **촬영 위치(GPS)·기기 정보를 지워요.**
  - 서버는 진짜 JPEG인지 확인하고, 2MB가 넘으면 거절해요. 파일 이름은 서버가 무작위로 정해요.
  - 사진은 로그인 없이 볼 수 있으니 **학생 얼굴이 나오지 않게** 찍어 주세요.
- `.env`, `data/`, `certs/`는 **다른 사람과 공유하지 마세요** (`.gitignore`에 들어 있어요).
- **알아 둘 한계**
  - 학생 본인 확인이 "학번"뿐이에요. 다른 학생의 학번을 아는 사람은 그 학생 대신 반납·종료를 누를 수 있어요.
  - 인식 기록 주소는 로그인 없이 쓸 수 있어서, 마음먹으면 가짜 기록으로 정확도 통계를 흐릴 수 있어요.
- 💰 **돈이 드는 서비스는 쓰지 않아요.** 나중에 문자 메시지·카카오 알림톡을 붙이려면 **유료**이니 요금을 먼저 확인하세요. 알림 코드는 `src/notify.js` 한 파일에 모여 있어요.

### 나중에 할 수 있는 것
- **학교 주소(URL)로 바꾸기:** 지금은 `localhost`나 숫자 IP 주소로 들어와요. 무료로 학교 안에서만 쓰는 방법(고정 IP + `scilab.local` 같은 이름)과, 돈이 드는 방법(도메인·인터넷 공개)이 있어요. 인터넷에 공개하면 학생 정보가 노출될 수 있으니 학교 정보부와 먼저 상의하세요.
- **문자·메신저 알림:** `src/notify.js` 한 파일만 고치면 돼요. 문자·카카오 알림톡은 **유료**이고 학생 정보가 학교 밖으로 나가요.
- **AI로 추천하기:** `src/rules/recommend.js` 의 `recommend()` 만 바꾸면 돼요. AI는 **사용할 때마다 요금**이 들어요.
